one dashboard.

## 🧵 Features / Modules

1. **Raw Material Requirement Prediction** — ML models (Linear Regression, Random Forest, Decision Tree,
   Gradient Boosting, XGBoost) compared automatically; best model auto-selected per material.
2. **Inventory Management** — stock tracking, history, low-stock alerts.
3. **Production Planning** — daily/weekly/monthly forecasts, efficiency, delay risk, AI suggestions.
4. **Cost Prediction** — raw material, production, labour, electricity, transport cost + profit margin.
5. **Material Wastage Prediction** — waste %, quantity, cost, root cause, AI recommendations.
6. **Supplier Recommendation** — multi-criteria ranking (price, quality, delivery, rating, availability).
7. **Order Priority Prediction** — High/Medium/Low based on delivery urgency, size, customer, machine availability.
8. **AI Insights** — plain-English, rule-based business insights generated from live data.
9. **Reports** — PDF & Excel export for inventory, production, analytics, and dashboard summaries.
10. **Analytics Dashboard** — pie, bar, line, scatter charts + correlation heatmap, monthly/yearly trends.

   ```bash
   python -m venv venv

   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application**
   ```bash

   ```

   You do **not** need to run the dataset/training scripts manually; they're provided separately only if
   you want to regenerate data or retrain on demand (e.g. after editing `generate_dataset.py`).

### ⚠️ Important: why models are NOT pre-included

The `saved_models/` folder ships empty on purpose. Trained model files (`.pkl`) are tied to the exact
versions of `numpy`, `scikit-learn`, and `xgboost` used to create them — copying `.pkl` files between
machines with different library versions can cause errors like:

```
ValueError: <class 'numpy.random._mt19937.MT19937'> is not a known BitGenerator module.
```

To avoid this permanently, the app trains its own models locally the first time it runs, guaranteeing
they always match your installed library versions. If you ever see a similar error anyway (e.g. after
manually copying a `saved_models/` folder from another PC), just delete everything inside `saved_models/`
and restart the app — it will retrain automatically.

## 📊 Machine Learning Approach

- Categorical features are label-encoded; numeric features are standardized.
- Five regression algorithms are trained per material target and compared using **MAE**, **RMSE**, **R² Score**,
  and 5-fold cross-validation.
- The best-performing model (lowest RMSE) is automatically saved and used for live predictions.
- Re-run `train_material_prediction.py` any time the dataset is refreshed to retrain models.

## 🔐 Security Notes
